# Stock Portfolio Performance Tracker

## About the Project

The Stock Portfolio Performance Tracker is a Python-based application developed as part of the Datheon Python Programming Internship.

It helps users manage their stock investments and monitor their portfolio performance by calculating investment values, profits, and losses.

## Features

- Add stocks to the portfolio.
- View all saved stocks.
- Calculate total investment.
- Calculate current portfolio value.
- Calculate profit or loss.
- Remove stocks from the portfolio.

## Technologies Used

- Python 3
- Python Dictionaries
- Functions
- Loops and Conditional Statements

## How to Run

1. Make sure Python 3 is installed.
2. Open a terminal in the project folder.
3. Run the following command:

```bash
python main.py
```

## Example

Suppose a user buys:

- Stock symbol: AAPL
- Number of shares: 10
- Purchase price: 150

If the current price is 170:

- Total investment: 1500
- Current value: 1700
- Profit: 200
