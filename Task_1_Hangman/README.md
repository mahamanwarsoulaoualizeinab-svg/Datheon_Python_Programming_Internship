Task 1 — Hangman Game

About the Project

This project is a command-line Hangman game developed in Python as part of the Datheon Python Programming Internship.

The player tries to guess a hidden word by entering one letter at a time. The player has a limited number of attempts to find the correct word.

Features

- Random word selection
- Letter-by-letter guessing
- Maximum of 6 incorrect attempts
- Detection of repeated and invalid guesses
- Win or lose messages
- Option to play again

Technologies Used

- Python
- Random module

How to Run

1. Make sure Python is installed.
2. Open a terminal in the "Task_1_Hangman" folder.
3. Run the following command:

python hangman.py

Project Files

- "hangman.py" — Main game code
- "Words.txt" — Word list used by the game
- "README.md" — Project documentation
