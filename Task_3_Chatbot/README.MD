# Task 4: Rule-Based Interactive Terminal Assistant / Chatbot

## Project Description

This project is a rule-based interactive chatbot developed
in Python.

It responds to greetings and frequently asked questions
using keyword matching and regular expressions.

## Features

- Recognizes greetings.
- Answers frequently asked questions from a JSON file.
- Uses regular expressions for text matching.
- Provides responses to unknown questions.
- Supports exit commands such as bye, exit and quit.
- Runs interactively in the terminal.

## Project Files

- `chatbot.py`: Main chatbot application.
- `sample_faq.json`: FAQ and greeting dataset.

## Requirements

- Python 3

No external Python libraries are required.

## How to Run

Open the terminal in the project folder and execute:

```bash
python chatbot.py
```

## Data Source

The chatbot uses the sample FAQ JSON file provided
for the internship task.
